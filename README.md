# 🏫 School Website

A modern, responsive school website built using **HTML, CSS, and JavaScript**.
This project is designed as a multi-section educational website showcasing school information, academics, admissions, and student life in a clean and structured layout.

---

## 🌐 Live Demo

```
https://takeo-dev.github.io/school-website/
```

---

## 📸 Features Preview

* 🎥 Hero section with background video
* 🧭 Multi-level mega navigation menu
* 🏫 Structured pages (About, Academics, Admissions, School Life)
* 🎓 Interactive Academics section (click-based UI)
* 📱 Responsive layout for better user experience
* 🎨 Modern UI with images and hover effects
* 📌 Organized footer with links and social icons

---

## ✨ Features

### 🏠 Home Page

* Full-screen video background
* School introduction and call-to-action button

### 📚 Academics Section

* Nursery, Primary, Middle School, Grade 8
* Interactive card switching using JavaScript
* Engaging learning-focused descriptions

### 🧾 Admissions Section

* Admission information and process
* Clean layout for parents and students

### 🏫 School Life

* Arts, Athletics, Clubs, Camps
* Student activity-focused design

### 📌 Navigation System

* Dropdown + mega menu design
* Easy access to all sections
